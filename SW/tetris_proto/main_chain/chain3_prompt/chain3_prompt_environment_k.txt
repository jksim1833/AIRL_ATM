[user] 
차량 내부는 4개의 독립된 셀로 구획되어 있으며, 각 셀에는 하나의 회전판과 그 위에 하나의 시트가 있습니다. 
셀들은 서로 분리되어 있어, 서로 다른 셀의 시트끼리는 충돌하지 않습니다. 
시트에 대한 정보는 Python 딕셔너리 형태로 주어집니다. 
**“초기 상태”는 항상 동일합니다.**
"""
[초기 상태]
{
  "seats": {
    "1": { "rail_axis": "x", "position": "M", "facing": "F", "mode": "chair" },
    "2": { "rail_axis": "x", "position": "M", "facing": "F", "mode": "chair" },
    "3": { "rail_axis": "x", "position": "M", "facing": "F", "mode": "chair" },
    "4": { "rail_axis": "x", "position": "M", "facing": "F", "mode": "chair" }
  }
}

"""
시트 상태는 다음을 사용해 표현합니다:
"""
"시트 상태 리스트"
- rail_axis: "x" | "y" 
  (회전판 내부에 설치된 직선 레일의 방향: x=X축 방향, y=Y축 방향)
  
- position: "A" | "M" | "C" 
  (레일을 따라 고정된 3개의 위치: A=음의 끝점, M=중앙, C=양의 끝점)

- facing: "F" | "R" | "B" | "L" 
  (차량 기준 절대 방향: F=앞, R=오른쪽, B=뒤, L=왼쪽)

- mode: "chair" | "storage" 
  (시트의 물리적 형태: chair=펼쳐진 상태, storage=접힌 상태)
-------------------------------------------------------
